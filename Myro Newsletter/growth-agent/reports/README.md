# Reports

Reports capture what happened, what worked, and what changes tomorrow.

## File Naming

```text
daily-YYYY-MM-DD.md
weekly-YYYY-MM-DD.md
```

Examples:

```text
daily-2026-05-18.md
weekly-2026-05-24.md
```
