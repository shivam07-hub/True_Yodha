# Weekly Playbook

The weekly loop keeps the 60-day target honest. It prevents the agent from confusing activity with growth.

## Monday: Gate Check And Plan

Read the latest daily reports and compare totals against the active gate.

Weekly planning output:

```text
Week:
Account target:
Activation target:
Current accounts:
Current activations:
Gap:
Top channel from last week:
Weakest channel from last week:
This week's three experiments:
Assets Shivam must review:
```

## Wednesday: Channel Review

Compare sources by activation, not just clicks.

Decisions:

- Increase channels that create activated users.
- Rewrite channels that create clicks but no signups.
- Pause channels that create poor-fit traffic.
- Keep community replies manual-quality even when drafts are generated by the agent.

## Friday: Experiment Review

For each experiment, record:

- hypothesis,
- post or channel,
- CTA,
- accounts created,
- activations,
- learning,
- next action.

## Sunday: Lock Next Calendar

Create or revise the next 7 days in `content-calendar.md`.

Every day should have:

- one primary claim,
- one CTA campaign slug,
- one channel focus,
- one community angle.

If signup-to-activation conversion drops below 50%, improve onboarding and CTA fit before increasing content volume.
