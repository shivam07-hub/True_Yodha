# Job Intelligence Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a scalable backend for Feed State, structured Job Feedback,
privacy-safe Job Pulse, and dashboard lifecycle fields.

**Architecture:** Add one deep `JobIntelligence` module backed by a focused
Supabase repository. Canonical feedback and application rows feed a
read-optimized snapshot maintained in Postgres; routers expose three bounded
interfaces for both web and mobile clients.

**Tech Stack:** FastAPI, Pydantic, Supabase/PostgREST, PostgreSQL triggers,
pytest.
