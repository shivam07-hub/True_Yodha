Zero active postings in the Myro database say "loop engineering." One says "prompt engineer." But **213 say "Generative AI Agents," 146 say "Agentic AI," 30 say "AI Agent Monitoring" and 25 say "AI Agent Observability."** The job is being hired at scale right now. The market just hasn't agreed on the word.

Loop engineering is that word, coined by Anthropic's Claude team. Here's what it is, and how to be doing it in 90 days, before the title reaches job descriptions.

### TL;DR

- **"Loop engineering": 0 postings. The work behind it: 500+.** The term lags the practice.
- Prompt engineering is the words. **Loop engineering is the system around them:** evals, guardrails, budgets, traces.
- Closest hiring signals today: **Generative AI Agents 213, Agentic AI 146, Agent Monitoring 30, Agent Observability 25**.

## What loop engineering actually is

An AI agent is a loop: think, call a tool, read the result, decide again. Loop engineering runs that loop like a production system. Evals score each run against known-good cases. Guardrails stop one that's looping, over-spending or going off the rails. A cost and latency budget keeps it shippable. Observability tells you what the agent did when it failed at 2 a.m.

Filing this under prompt engineering is the common mistake. The words are maybe 10% of a reliable agent; the machinery around them is the rest, and it's what those Agent Monitoring and Observability postings quietly ask for.

## The 90-day plan to land it

**Days 0–30, Foundation.** Build one tool-using agent that does a real task end to end. Instrument every run: inputs, tool calls, output, cost. Read Anthropic's engineering writing on agents and harnesses as you build.

**Days 31–60, Build.** Add an eval harness of 20+ scored cases the loop must pass, plus two guardrails: a stop condition and a budget cap. Break it on purpose and watch the traces catch it.

**Days 61–90, Ship.** Point it at messy real inputs, add tracing, and write up the failure modes you caught and how the loop recovered. That writeup is your portfolio piece.

## What this means for you

**Early-career.** No "AI" title required. Instrument one agent loop well, then apply to the 30 "AI Agent Monitoring" roles that want exactly that.
